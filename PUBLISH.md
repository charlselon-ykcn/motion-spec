# GitHub publication

The repository homepage (`README.md`) and GitHub Pages root (`index.html`) use English by default. Chinese readers can use `SPEC.zh.md` or `zh.html`; `SPEC.en.md` and `en.html` remain available as English entry points.

GitHub Pages publishes the repository root from the `main` branch. The pages are static and require no build, login, or online generation service.

- `README.md`: English format specification.
- `SPEC.zh.md`: Chinese format specification.
- `PERSONAL.en.md` / `PERSONAL.md`: optional MotionGit personal delivery profile.
- `HISTORY.en.md` / `HISTORY.md`: version and compatibility history.
- `LEGACY.en.md` / `LEGACY.md`: existing content contract.
- `schema/`: JSON Schema documents.

No real account keys, personal download packages, server configuration, or private projects are included. The owner must choose any open-source license for repository documents and code; publishing the format does not grant rights to template assets.
